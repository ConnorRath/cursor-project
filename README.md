## Cursor Exploration Prompts

Clone this project to your local machine and then after downloading and setting up cursor, have it analyze this repo!

Try asking Cursor:
- How would I run this?

- Explain how todos are stored

- Why is a list of dictionaries used?

- Walk through the add_todo function

- What happens if I remove try/except?

- Refactor this into a Todo class

- Add file persistence using JSON

- Convert this into a GUI app
